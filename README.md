# RoosterWorks Ground Modules v0.8.0

Build surface bases for KSP 1.12.5 with habitats, laboratories, a greenhouse, connecting tubes, docking ends and ground industry.

- Exterior models include straight blue and yellow service wiring, mounted handrails, updated hull insulation and higher-resolution instrument textures.
- Landing legs respond to the stock Gear action group. Terrain fitting restores footpads in local coordinates when a vessel loads.
- Command modules can auto-level connected supports. The adjustable crew tube accommodates gaps between modules.

Install ModuleManager and RoosterWorks Station Modules, then extract the player ZIP into the KSP directory. Nuclear industry uses Community Resource Pack and SystemHeat.
